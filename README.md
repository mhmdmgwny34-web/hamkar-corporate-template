# قالب HTML شرکتی همکار
قالب فارسی و راست‌چین شرکتی با HTML5، CSS و JavaScript ساده.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای توسعه می‌توانید از Live Server استفاده کنید.

## فایل‌ها
- `index.html`: ساختار صفحه و محتوای نمونه
- `assets/css/style.css`: طراحی واکنش‌گرا و استایل‌ها
- `assets/js/main.js`: منوی موبایل، سال پویای فوتر، فیلتر نمونه‌کار و ساخت ایمیل از فرم تماس
- `favicon.svg` و `favicon-96.png`: نشان سایت برای تب مرورگر و نتایج جست‌وجو
- `apple-touch-icon.png`: آیکون میان‌بر در دستگاه‌های اپل
- `assets/images/`: تصاویر محلی بخش‌های اصلی، نمونه‌کار، اعضای تیم و مجله.

## نکات محتوای نمونه
- نام برند «همکار»، آمار داشبورد، متن‌ها و نمونه‌کارها صرفاً نمایشی هستند و نباید به‌عنوان اطلاعات واقعی منتشر شوند.
- اطلاعات تماس و ساعات پاسخ‌گویی در این نسخه عمداً درج نشده‌اند؛ آن‌ها را فقط مطابق ضوابط محل انتشار و اطلاعات واقعی خودتان تکمیل کنید.

## پیش از انتشار
- نام برند، متن‌ها و اطلاعات تماس مجاز را جایگزین کنید.
- پروژه‌های نمونه را با نمونه‌کارهای واقعی جایگزین کنید.
- فرم تماس با جایگزینی مقدار `data-recipient="your-email@example.com"` در فرم‌های `index.html` و `contact.html` با ایمیل واقعی دریافت‌کننده، برنامه ایمیل کاربر را با متن آماده باز می‌کند. کاربر باید ارسال را در برنامه ایمیل تأیید کند؛ این روش پیام را در سرور ذخیره نمی‌کند و جایگزین بک‌اند نیست.
- فونت Vazirmatn به‌صورت محلی از مسیر `assets/fonts/vazirmatn-variable.woff2` بارگذاری می‌شود؛ بنابراین برای نمایش فونت به Google Fonts وابسته نیست.
- فایل مجوز فونت در `assets/fonts/OFL.txt` قرار دارد. فونت Vazirmatn تحت مجوز SIL Open Font License 1.1 منتشر شده و همراه قالب بازتوزیع شده است؛ متن مجوز را حفظ کنید.
- فونت Vazirmatn با مجوز SIL OFL 1.1 همراه فایل مجوز ارائه می‌شود. مجوز تجاری و حق بازتوزیع تصاویر پوشه `assets/images/` باید پیش از فروش از منبع اصلی آن‌ها بررسی و مستند شود؛ در این مخزن مدرک مجوز تصاویر ثبت نشده است.


## نشان سایت و اطلاعات سئو
برای سایت favicon برداری و PNG با اندازه ۹۶×۹۶ پیکسل تنظیم شده است. عنوان صفحه، توضیحات متا، Open Graph و کلمات کلیدی مرتبط نیز در بخش `head` قرار دارند. نمایش favicon در نتایج جست‌وجو به تصمیم و زمان‌بندی خزنده موتور جست‌وجو وابسته است و تضمین‌شدنی نیست. گوگل از meta keywords برای رتبه‌بندی استفاده نمی‌کند؛ عنوان، توضیحات و محتوای واقعی صفحه مهم‌ترند.

## اعتبار فونت
فونت Vazirmatn اثر پروژه Vazirmatn است و با مجوز SIL Open Font License نسخه 1.1 استفاده شده است. این فونت متعلق به سازنده قالب نیست؛ فایل مجوز اصلی در پوشه فونت همراه قالب قرار دارد.

## وضعیت و چک‌لیست انتشار
این بسته یک قالب HTML استاتیک است. پیش از انتشار نهایی، ایمیل مقصد فرم‌ها را تنظیم کنید، مجوز تجاری و بازتوزیع تصاویر را از منبع اصلی تأیید کنید، محتوای نمونه را جایگزین کنید و تست نهایی را در مرورگرهای هدف انجام دهید. موبایل توسط سازنده بررسی شده است؛ تست مستقل همه مرورگرها در این مخزن ثبت نشده است.


## تصاویر قالب
تصویرسازی‌های فعلی با CSS ساخته شده‌اند و فایل عکس شخص ثالثی در بسته نیست.

## امکانات نسخه توسعه‌یافته
- بخش نظرات مشتریان، اعضای تیم، پلن‌های تعرفه نمونه و پرسش‌های متداول
- فیلتر دسته‌بندی نمونه‌کارها و نمایش بزرگ تصاویر با پنجره بومی dialog
- بخش مجله و صفحه فهرست مقاله‌ها در blog.html
- اسلایدر نظرات با کنترل صفحه‌کلید و اعلام وضعیت برای فناوری‌های کمکی

## محتوای نمایشی
نظرات، اسامی اعضای تیم، تعرفه‌ها و مقاله‌ها محتوای نمونه‌اند؛ آن‌ها را به‌عنوان اطلاعات واقعی منتشر نکنید. فرم تماس از طریق برنامه ایمیل کاربر عمل می‌کند و برای ارسال خودکار یا ذخیره‌سازی به بک‌اند نیاز دارد.

## صفحات چندگانه
- `services.html`: معرفی جزئی خدمات
- `about.html`: درباره ما و ارزش‌ها
- `portfolio.html`: گالری نمونه‌کار با فیلتر و لایت‌باکس
- `contact.html`: صفحه تماس با فرم آماده ساخت ایمیل (پس از تنظیم ایمیل مقصد)
- `blog.html`: مجله و سه مقاله نمونه
- `sitemap.xml` و `robots.txt`: فایل‌های پایه موتورهای جست‌وجو

اطلاعات تماس، نمونه‌کارها و متن‌های معرفی در این صفحات نمایشی‌اند و باید با داده‌های واقعی خریدار جایگزین شوند. فرم تماس پس از جایگزینی `your-email@example.com` در ویژگی `data-recipient` هر دو فرم با ایمیل مقصد، برنامه ایمیل کاربر را با متن آماده باز می‌کند. برای ارسال مستقیم و ذخیره‌سازی پیام باید سرویس فرم یا بک‌اند متصل شود.
